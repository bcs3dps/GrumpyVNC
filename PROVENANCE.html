GrumpyVNC is a self-contained fork. It carries vendored copies of its upstream project and of every dependency, so it builds from a single clone with no network access and no git submodules — nothing here depends on an external repository continuing to exist. Each vendored component keeps its own licence file; refer to that file for its terms.

Upstream fixes are applied by hand from the sources below. There is no live tie to any of them; the URLs are recorded for credit and so a maintainer knows where to pull a fix from.

This fork’s upstream

  • grumpyscreen — https://github.com/pellcorp/grumpyscreen (GPL-3.0), itself a fork of GuppyScreen (https://github.com/ballaswag/guppyscreen).

GrumpyVNC adds, on top of grumpyscreen, a built-in RFB/VNC server (vnc/, with a DES engine for VNC authentication), an ARMv6 cross-build (crossbuild/), and Centauri / C2 integration. Those additions are Copyright (c) 2026 B. C. Services, GPL-3.0.
